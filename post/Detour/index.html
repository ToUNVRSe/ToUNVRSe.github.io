弯路

First Post:
2025-04-03

Last Update:
2025-04-04

手稿写于 3/27

老一辈人常教导我如何可以少走些弯路，他们的善意我无法拒绝，但我总还是忍不住孩子气地（其时我确实是孩子，现在应当也算是！）在末尾回应道如果所有人都走弯路的话，那世上应早就没有弯路可走了。

后来我的确（至少自以为是的）走了一些弯路，我忽地就获得了那种试图劝服别人的心境，就好像一下老了许多，又像是幼稚了许多地希望把所有人排除在这条路外，以示对它的惩罚。可我又暗暗地见不得别人被这路引到对岸去，怕刺痛了自己。也许我还是有着一颗一叶障目的魔鬼的心灵，我最后的手段就是我不信教。

想来曾在 CF1上看到论证一次偶然的掉分会很快被抹平的帖子，可他假设我还会满怀热情地去打啊。可我是个会被挫败的人，也不够强让我的 CP2一直持续下去，现在我大概再也不会打 CF 了，那些掉的分也就不会再回来了。

当然，我也会想要是我从来就不打 CP 就好了，这样连 CF 分也不会掉了。我又想到如果随机轴是固定的，打 CP 吃掉个大烂随机数也不错。可万一它们与日常琐事也用一个轴呢？那 CP 就确实没什么用了。可是我还是权衡不了打 CP 遇上的好事与坏事，就像打 CF 一样只要满怀热情地打就算 CF 掉分了也许别的地方会涨分吧？如果一辈子都不涨的话那下辈子如何呢？如果这么糟糕的话那与 CP 也没什么关系了吧？

其实我还是在用呓语安慰自己，我会说其实本来也没什么弯路可走，因为弯路对应直路，可我从出生起就见不到什么直路可走啊，难道把整天操心的分数从 600 分换成 750 分就算是直路了吗？我不过是在诸多弯路中选择一条喜欢的罢了，而现在我不再那么喜欢它，也许因为我没有选择另一条而已。可其实我就是功利的，如果我成功了我再不会理会其他的弯路了。

我还是常退步地怀有机械论的观点，人在自然的法则中怎么会生出独立性来呢？像物质的人并不因为他不爱求知，因为他不知什么是知识；像软弱的人并不因为他没有勇气，因为他不知勇气有用。物理一样准确无误的。若有一日我做了什么，或决定什么也不做，同样是先前决定的，所以我决定做些什么，反正都是已被决定要做的。

那么我疲累、懦弱、冷漠，都不算天大的罪过，我忠实地走完一段弯路，然后哭一场，理所当然的。如果我那时见到之后的我说一些安慰的话，那时的我也一定会让面前的傻瓜滚蛋然后继续流泪。除非他说我 750 分拿的如何如何多，那就有商榷的空间。但还是因为少活一年而不好说。而且现在看来不太可能。


补：感觉自己文字还是走了太多弯路而徒劳熵增，不过按照一些理论文字的弯路越长越好，而其他人制造的熵比我多多了，所以没什么。大概别人也这么想吧，只是希望都发现了其中的矛盾。
